# Wedding Template Website 💍

A simple and elegant wedding website template designed to help couples share their special day details with guests in a beautiful, modern way.

This is my first wedding template website project.

---

## ✨ Features

- Responsive design (works on mobile, tablet, and desktop)
- Elegant and minimal wedding-themed layout
- Wedding date & schedule
- beutiful animations
- countdown
- Easy to customize content and styling
- Lightweight and fast loading

---

## 🛠️ Built With

- React(typescript)
